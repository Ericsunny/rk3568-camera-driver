## 4. 环境搭建手册(可复现步骤,逐步登记在 §5)

### 4.1 PC 侧克隆(ghfast 镜像,VM 直连 GitHub 慢)
```bash
cd /d/vm/github
git clone --depth 1 https://ghfast.top/https://github.com/airockchip/rknn-toolkit2.git
git clone --depth 1 https://ghfast.top/https://github.com/airockchip/rknn_model_zoo.git
```

### 4.2 VM:venv + toolkit2 安装
```bash
# scp 传输(PC 上执行)
scp -r /d/vm/github/rknn-toolkit2 rk3568:~/
# VM 内
python3 -m venv ~/rknn-venv && source ~/rknn-venv/bin/activate
pip install rknn-toolkit2/packages/py38/*.whl numpy==1.xx   # 版本按轮子要求
python -c "from rknn.api import RKNN; print('toolkit2 OK')"
```

### 4.3 板上 librknnrt 升级(配套,先备份)
```bash
# PC:从 toolkit2 仓取配套 aarch64 runtime 推板
scp rknn-toolkit2/rknpu2/runtime/Linux/librknn_api/aarch64/librknnrt.so rkboard:/usr/lib/librknnrt.so.new
# 板:备份 → 替换 → 验证
cp /usr/lib/librknnrt.so /usr/lib/librknnrt.so.bak-1.5.0
mv /usr/lib/librknnrt.so.new /usr/lib/librknnrt.so && ldconfig
strings /usr/lib/librknnrt.so | grep -m1 -i version    # 应显示新版本号
```
