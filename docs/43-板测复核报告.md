## 预注册 W1：IMX415 两帧

- **输入与条件**：在以上 boot、现役 3A 保持运行、当前 `/dev/video5` 为 3840×2160 NV12、stride 3840 的情况下，在私有目录抓同一采流会话的连续两帧。不更改传感器模式、不停止或重启 3A；抓取前复核格式、空间与节点占用。待测工具 `v4l2-ctl` 两端哈希见上；脚本执行前两端 MD5 也必须一致。脚本与准确命令见 [W1-twoframes.sh](../evidence/2026-11-05-板测复核/W1-twoframes.sh)，其核心命令为 `timeout 20s v4l2-ctl -d /dev/video5 --stream-no-query --stream-mmap=3 --stream-count=2 --stream-to=<run>/two.nv12`。
- **判据（采集前冻结）**：退出 0 且总文件长度 24,883,200 字节；切出的两帧各 12,441,600 字节；各自 MD5/SHA-256 与完整日志留存。两帧内容不同时只支持“这两次输出不完全相同”，不单凭 MD5 差异证明画质或不存在缓存问题；两帧相同为未定，可能是静止场景等因素，不直接归因死流。超时、尺寸不对、3A 状态变化或记录不完整为无效，不改阈值补判。
- **风险与路径**：占用 ISP、写入约 50 MB，按已授权窗口进行；不启动/停止服务、不重启、不覆盖现役文件。板端独立目录预定为 `/root/camera-window/review-20261105-1015Z-c08f2a`，经核对脚本 MD5 后执行 `sh /root/camera-window/review-20261105-1015Z-c08f2a/W1-twoframes.sh /root/camera-window/review-20261105-1015Z-c08f2a`；stdout/stderr、退出码和哈希在本仓库证据目录另存 W1 新文件，逐个核验 MD5；视频帧不自动入库。超时不保证解除内核 D 状态，若节点失联立即停止后续实验并保留现场。
- **状态**：未执行；采集前须记录脚本双端哈希、确切 run 路径、完整 stdout/stderr 与退出码。
