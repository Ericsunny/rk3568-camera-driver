# IMX415 采集：获取第一帧

IMX415 的原始数据经 CSI 和 ISP 处理后，可从 V4L2 mainpath 取得 NV12。项目中的采集、编码和推流以这条链路为基础；OV8858 的 CIF RAW10 是另一条链路，不能按 NV12 解释。

```text
IMX415 → CSI-2 → ISP → V4L2 mainpath → 用户态采集
```

## 先确认拓扑和格式

设备节点号可能随内核和枚举顺序变化。先用 `media-ctl -p` 找到 sensor、ISP 与 mainpath 的连接，再用 `v4l2-ctl --all` 检查目标节点当前格式、分辨率、bytesperline 与 sizeimage。不要仅凭 `/dev/video0` 或 `/dev/video5` 推断节点职责。

例如，在无额外行填充的 3840×2160 NV12 中，一帧为 `3840 × 2160 × 3 / 2 = 12,441,600` 字节；实际分配大小以驱动返回的 stride 和 sizeimage 为准。大小符合预期只说明文件长度匹配，不能单独证明图像内容正确。

## 怎样判断出图

1. 在确认设备没有被其他采集程序占用、3A 状态合适后，使用独立路径保存采集帧，不覆盖现役文件。
2. 核对采集命令的退出码、帧数及文件长度，再按实际格式和 stride 打开图像，检查是否有合理的亮度、结构和色彩。
3. 如需验证画面随场景变化，保持格式不变、改变镜头前的物体并取多帧。不同哈希只说明字节不同，也可能来自噪声；相同哈希也不自动等于全零。需要结合场景变化和像素内容判断。
