# IMX415：rkaiq 与 3A

IMX415 在本项目中通过 ISP 输出 NV12。rkaiq 用户态服务读取 ISP 的统计信息，计算自动曝光、自动白平衡等参数，并通过相应接口影响后续帧。它与应用采集图像是相关但不同的工作：应用不能因为抓到帧，就认定 3A 已正常收敛。

```text
sensor 出帧 → ISP 统计 → rkaiq 计算 → ISP / sensor 参数 → 后续帧
                                      ↓
                                应用采集 NV12
```

统计和参数节点的 `/dev/videoN` 编号会随内核及枚举改变，先用 `media-ctl -p` 和 `v4l2-ctl --info` 确认节点职责。镜头及模组相关的 IQ 配置需要与运行库、传感器和场景匹配；进程存活或数值变化本身不证明曝光和白平衡的效果正确。

历史实验里出现过库与 IQ 配置不匹配、服务崩溃以及曝光结果不稳定。原因、不同组件组合与对照结果见[白平衡实验](../image/awb.md)和[历史环境说明](../acceptance/reproduction.md)。这些结论限定在当时版本与场景，不能直接外推到当前板端。

3A 服务与采集的生命周期存在共享硬件风险。操作前应确认现役服务及采集状态；不要在采流中停止或强杀现役 3A。[恢复记录](../runbook/boot-recovery.md)保留了历史事故及边界。
