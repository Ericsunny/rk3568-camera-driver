# 2026-10-27 4K 服务级 soak(2 小时)

## 形态

- 内核 **#52**(md5 `04672f71`),3A 常驻 active,IMX415@J10 + OV8858@J11;
- 服务:`evrec -d /dev/video5 -w 3840 -h 2160 --detect --rtsp`(检测触发型事件录像 + RTSP 8554);
- 时长 **7205 s(2 h)**,`timeout -s TERM` 优雅终止(日志尾"收到 SIGTERM, 已停止");
- 采样:内联循环每 60 s 一行(共 **100 行**;soak_monitor attach 模式未生效,见待办);
- 模型 `yolov8n_rk3568_i8.rknn`(94fde17f),librknnrt 2.3.2(出厂 1.5 备份 `.bak-factory`)。

> 注:本形态为 4K(非 10-25 的 1080p soak)——IMX415 1080p 模式被厂商表缺陷挡住(issue #3),
> 只能以 4K@~7.3 fps 带检测运行。

## 结果:稳定性 PASS(口径收窄)

| 指标 | 结果 | 判定 |
|---|---|---|
| 总帧数 | **52 556 帧 / 7205 s = 7.3 fps**(RGA 19.56 + RKNN 62.36 + 编码 54.87 = 136.8 ms/帧,与冒烟一致) | 全链无中断 |
| RSS | 首 90 644 KB → 尾 90 268 KB;**峰值 126 456 KB 仅 2/100 样本**(第 85/86 号,事件密集落盘瞬时,前后回落) | **有界,无泄漏** |
| fd | **恒 30**(全部 100 样本) | 有界 |
| 温度 | 53.1 ~ 55.0 °C | 有界 |
| dmesg | `timeout/Unable to handle/params stream on event` 计数 **0** | 无内核错误 |
| 事件 | **932 次检测触发、834 个事件文件落盘**(h264+json 成对;镜头前持续目标,score 0.80~0.82) | 事件路径真实压过;**持续目标未合并成同一事件——event coalescing/retention 缺口,另立 issue 处理** |
| RTSP | `rtsp-ring in=52556 drop=0`(**无真实客户端,仅服务端空载**) | 空载运行正常;**不能证明多客户端/慢客户端/重连** |
| 退出 | SIGTERM 优雅退出,落盘完整 | 正常 |

## 结论口径(三条边界)

1. **7.3 fps 是"检测+编码串行负载"下的结果,不是 4K 采集能力**——4K 线性基线为 14.73 fps(evidence/2026-10-27-HDR线性基线)。
   本 soak 的验收口径是"全链不中断、资源有界",故 PASS;若目标是 10/15 fps 服务性能,则未达标。
2. **RTSP 仅空载运行**——服务端 2h 无客户端拉流,`drop=0` 只说明投递环没丢;
   多客户端/慢客户端/断线重连/真实解码均未验证,不在本 PASS 覆盖内。
3. **834 个事件文件是事件治理缺口**——持续目标应延长同一事件或进入冷却,而非每几秒生成新文件;
   按 ~1.9MB/事件外推 24h 会写满分区。已另立 issue,**不并入 soak 结论**。
