# 2026-10-30 arena 对照(中断, 结论=斜率对比不成立 + 空闲稳定性新证据)

## 绑定与配置

- binary = /tmp/h3src/evrec_ts md5 **ccd5fd75**(main@c9725a2 源码, 板上重编,
  与 10-29 回绕测试二进制逐字节相同=第三次复现)
- 板子夜间重启过(up 1min 起部署, /tmp 全清重传); `MALLOC_ARENA_MAX=2`
  已核实进进程 environ
- 计划负载 = V7 同款双客户端 14640s(4h04m)

## 中断事实

双客户端于挂载 **58 分钟**后同刻 ECONNRESET(errno=104)断开——两客户端同刻
死亡 = PC 侧事件(睡眠/网络), 非板端; 服务端干净断连, 之后继续存活采样至
4h30m。斜率对比(arena vs V7 等负载)因此**不成立**, 不下"变平/不变平"结论。

## 仍然有效的两条观测

1. **新鲜开机基线 rss=24.1MB**(此前所有基线都在开机后数小时取, 47~50MB)——
   RSS 绝对值强烈依赖开机后历史, 跨天比绝对值无意义, 只能比斜率;
2. **断载后 3.5h 空闲期 RSS 稳在 51.7~57.4MB 零增长**(采样 227 针, fds 恒 14)——
   分配器把已用内存留在 arena 里不上还(预期行为), 且无任何爬升趋势。
   与 V7 的 +4.6MB/2h 合并看, 依旧**无泄漏特征**, 但 arena 归因仍待补。

## 复跑条件

PC 保持唤醒(或接电源+改睡眠策略)再跑满 4h; 重部署三源重编(md5 应仍
= ccd5fd75)+ `MALLOC_ARENA_MAX=2` + 双客户端 14640s + v7mon 采样,
与 V7(默认 arena, 同负载 2h, 49.5→54.1MB)对齐后才有斜率可比性。
